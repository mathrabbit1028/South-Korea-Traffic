# 대한민국 실시간 주요도로 교통흐름 표시기

> 네이버지도 '교통정보' 기반 (https://rtt.map.naver.com/end-traffic/ends/web/home)

## 전국 고속도로/국도 ✅

Rust(Axum) 서버가 네이버지도 실시간 교통정보 화면에서 사용하는 JSON 데이터를 받아
주요 고속도로 구간을 그래프로 표시합니다. 각 간선의 평균속도는 `거리 ÷ 소요시간`으로
직접 계산하며, 속도 단계에 따라 초록·연두·주황·빨강·보라로 표시합니다.

### 실행

```bash
cargo run
```

브라우저에서 `http://localhost:3000`을 열면 됩니다. 데이터 요청은 90초 동안 캐시되며,
화면의 새로고침 버튼으로 즉시 다시 가져올 수 있습니다.

- 네이버 교통정보에 등록된 전체 고속도로 목록을 동적으로 조회
- 실제 대한민국 경계를 도로와 같은 Web Mercator 투영으로 표시
- 네이버 구간상세의 하위 위치를 간선 꺾임점으로 반영해 실제 노선 형태에 가깝게 표시
- 원본의 뒤집힌 상세좌표·잘못된 구간 끝점과 노선별 분기점 좌표 차이를 검증 후 보정
- 상·하행을 화면상 일정한 간격의 두 평행 간선으로 동시에 표시
- 평균속도별 간선 색상과 마우스 오버 시 방향별 소요시간 표시
- 휠·버튼 확대/축소와 드래그 이동
- 확대 배율에 따른 정점 크기 및 중요도별 지점명 표시
- 노선명·번호 검색, 노선·소통상태 필터 및 구간 상세 툴팁
- 화면 오른쪽의 양방향 선형 다이어그램에서 대표지역 24개 구간의 실시간 이동시간 확인
- 일부 외부 데이터 요청 실패 시 정상 노선만 계속 표시

> 네이버의 공식 공개 교통 API가 아니라 웹 교통정보 화면이 사용하는 내부 JSON 경로를
> 파싱합니다. 해당 경로의 변경 또는 접근 정책에 따라 연동이 중단될 수 있습니다.
